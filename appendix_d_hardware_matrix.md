## Overview

Every vector instruction set and matrix engine in the book, oldest first. *Bits* is the register width for
fixed SIMD, the architectural maximum for vector-length-agnostic ISAs, and the operand footprint of one
operation for matrix engines (see each row's note). Rows marked unconfirmed rely on secondary sources.

## Notes and sources

| Name | Note | Source |
|---|---|---|
| **Cray-1 vector registers** | 8 vector registers x 64 elements x 64 bit; a vector-length register sets how many elements an instruction processes; chaining forwards results between pipelines | Russell, The CRAY-1 Computer System, CACM 1978 |
| **MMX** | Integer only; registers aliased onto the x87 floating-point stack | Peleg & Weiser, MMX Technology Extension to the Intel Architecture, IEEE Micro 1996 |
| **AltiVec / VMX** | 32 vector registers and a general permute (vperm) from the start | Diefendorff et al., AltiVec Extension to PowerPC Accelerates Media Processing, IEEE Micro 2000 |
| **SSE / SSE2** | SSE2 is the x86-64 baseline: every 64-bit x86 CPU has at least 128-bit SIMD | Intel 64 and IA-32 Architectures Software Developer's Manual, Vol. 1, ch. 10-11 |
| **NEON (Advanced SIMD)** | Mandatory in AArch64 (32 x 128-bit registers); every phone CPU has it | Arm Architecture Reference Manual for A-profile |
| **CUDA SIMT warp** | 32 threads x 32-bit = 1024 bits of lanes, programmed as scalar threads. Every load is a gather; coalescing makes contiguous ones cheap | Lindholm et al., NVIDIA Tesla: A Unified Graphics and Computing Architecture, IEEE Micro 2008 |
| **AVX** | 256-bit floating point only; VEX three-operand encoding | Intel SDM Vol. 1, ch. 14 |
| **AVX2 + FMA3** | 256-bit integers, fused multiply-add, first x86 gather (vpgatherdd); x86-64-v3 baseline | Intel SDM Vol. 1, ch. 14 |
| **Hexagon HVX** | Very wide fixed vectors on a VLIW DSP; the classic home of on-device int8 inference | Codrescu, Qualcomm Hexagon DSP: An Architecture Optimized for Mobile Multimedia and Communications (Hot Chips 2013); Hexagon HVX Programmer's Reference |
| **TPU v1 MXU** | 65,536 8-bit MACs. width_bits counts 256 x 256 x 8-bit weights held in the array | Jouppi et al., In-Datacenter Performance Analysis of a Tensor Processing Unit, ISCA 2017 |
| **AVX-512** | 32 zmm registers, masking on almost every instruction, compress/expand, conflict detection (CD) for scatter | Intel SDM Vol. 1, ch. 15; Intel Intrinsics Guide |
| **TPU v2-v5 MXU** | Training generation; bfloat16 introduced. width_bits counts 128 x 128 x 16-bit | Jouppi et al., A Domain-Specific Supercomputer for Training Deep Neural Networks, CACM 2020 |
| **Tensor Cores (Volta)** | The warp, not the thread, issues the matrix op | NVIDIA Tesla V100 GPU Architecture whitepaper (2017) |
| **SVE** | Hardware chooses 128-2048 bits; the same binary runs on all. width_bits is the architectural maximum. First-faulting loads vectorize while-loops | Stephens et al., The ARM Scalable Vector Extension, IEEE Micro 2017 |
| **AMD wavefront + MFMA** | 64-wide wavefronts on CDNA (RDNA uses 32 or 64); the EXEC mask is the predication mechanism, visible in the ISA | AMD CDNA Instruction Set Architecture reference guides |
| **RISC-V V 1.0** | vsetvli returns how many elements this iteration may process; LMUL groups up to 8 registers. width_bits is the spec maximum VLEN | RISC-V V Vector Extension 1.0 specification (ratified 2021) |
| **SVE2** | Armv9 baseline; brings NEON's integer/DSP coverage to the VLA model | Arm Architecture Reference Manual, SVE2 supplement |
| **WebAssembly SIMD128** | Portable 128-bit SIMD that maps to SSE or NEON underneath; the reason in-browser ML runtimes can vectorize | WebAssembly SIMD proposal (Phase 4/5, 2021) |
| **Tensor Cores (Hopper, wgmma)** | width_bits counts the 4 warps of a warpgroup x 1024 | NVIDIA H100 Tensor Core GPU Architecture whitepaper (2022); PTX ISA wgmma |
| **AMX (TMUL)** | width_bits is one 1 KB tile; a tile op is a small matrix multiply, not a lane-wise op | Intel SDM Vol. 1, ch. 20 (Intel AMX) |
| **SME / SME2** | Outer-product engine: two vectors in, a whole tile updated. width_bits is M4's streaming vector length | Arm SME documentation; Remke & Breuer, Hello SME! (arXiv:2409.18779) |
| **TPU v6e / v7 MXU** | Google states the MXU grew for Trillium; the 256 x 256 size for v6e/v7 comes from secondary sources (unconfirmed) | Google Cloud blog, Introducing Trillium (2024); SemiAnalysis InferenceX glossary (secondary) |
| **Tensor Cores (Blackwell, tcgen05)** | Accumulators leave the register file entirely; consumer Blackwell (sm_120) has no TMEM | NVIDIA Blackwell architecture technical brief; PTX ISA tcgen05; Colfax CUTLASS tutorials |
| **AVX10.2** | Converges AVX-512 features under one versioned ISA; the 2024 spec revision made 512-bit support mandatory on all cores | Intel AVX10.2 Architecture Specification (2024); press coverage of Nova Lake support (secondary) |
